* et
=et= is an external typesystem and type-checker for elisp code, similar to [[https://www.typescriptlang.org/][Typescript]] (for Javascript) or [[https://mypy-lang.org/][mypy]]/[[https://microsoft.github.io/pyright/#/][Pyright]] (for Python).

To learn more about =et=, check out the [[https://benzanol.github.io/et/][documentation]].

*** Roadmap
=et= is currently *extremely experimental*. All APIs and behaviors are subject to change. The project is currently far from a complete or stable state.

The following items are currently considered to be priorities:
- 100% test coverage
- Type-annotations for more of the standard library
- =setf= handling
- More options for annotating local types (beyond just =et:/et!=)
- Early return handling such as /throw-catch/
- The program design needs to be better documented in [[./docs/implementation.org]].
- Getting the =et= package to fully type-check itself
- Non-strict mode + customizable strictness rules

*** AI Usage
- The core source files and documentation files should aim to contain zero AI-generated code/content.
- Some of the auxiliary code, and much of the standard library, is currently AI-generated.
| Documentation            | ~documentation/*.org~                | No AI                |
| Core source files        | ~et.el~, ~et-check.el~, ~et-annotate.el~ | No AI usage          |
| Auxiliary source files   | ~et-cache.el~, ~et-flymake.el~         | Substantial AI usage |
| Standard lib definitions | ~definitions/*~                      | Almost entirely AI   |
