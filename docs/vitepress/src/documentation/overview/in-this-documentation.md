# In this documentation

This documentation makes use of the following macros for demonstrative purposes:  

-   `(et TYPE-SYNTAX...)` - Parse a type
-   `(et-is? EXPRESSION TYPE)` - Type-check `EXPRESSION`, and determine if it is assignable to `TYPE`
-   `(et-typecheck EXPRESSION)` - Type-check `EXPRESSION` and output the resulting type

This documentation is best viewed within Emacs, where you can directly interact with the provided examples (plus create your own) to get a better feel for the system.
