# Introduction

`et` is an external typesystem and type-checker for elisp code, similar to [Typescript](https://www.typescriptlang.org/) (for Javascript) or [mypy](https://mypy-lang.org/)/[Pyright](https://microsoft.github.io/pyright/#/) (for Python).  

`et` defines:  

**1. A type-language for annotating elisp code**  
**2. A type-checker for statically analyzing the annotated code**
